# Bantu — African Instruments

Plugin VST3 gratuito para Windows com 12 instrumentos africanos (Djembe, Sabar, Dundun, Talking Drum, Ngoma, Shekere, Agogô, Udu, Kalimba, Balafon, Kora e Flauta), efeitos Warmth, Delay e Reverb, e um kit de bateria para os seus próprios samples.

**Página:** https://tonasmo.github.io/bantu/
**Descarregar:** [Bantu-1.0.0-Setup.exe](https://github.com/TonasMo/bantu/releases/latest)

Requisitos: Windows 10 ou 11 (64 bits) e uma DAW com suporte VST3 (FL Studio, Ableton Live, Reaper, Cubase, Studio One…). Inclui uma versão Standalone.

Este repositório contém só a página de download. O código do plugin não é público.
